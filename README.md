Pokedemy 포케데미: 포켓몬 통계, 팀빌딩, 학습까지!

## Pokedemy
Django와 React로 개발한 포켓몬 통계 웹서비스입니다.
REST Framework와 VITE를 사용해서 빌드했습니다.
link: https://www.pokedemy.co.kr

## Database 구축
DB는 PokeAPI의 데이터를 재가공하여 구축했습니다. 
웹: https://pokeapi.co/
Github: https://github.com/PokeAPI/pokeapi

## 계산 시스템
데미지 계산 시스템은 Pokemon Showdown이 사용하는 smogon calculator를 연동했습니다.
Github를 참고하며, 프로젝트에서는 smogon 라이브러리를 다운로드받아 연결했습니다.
Github: https://github.com/smogon/damage-calc
